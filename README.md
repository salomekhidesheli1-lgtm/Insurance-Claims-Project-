# Insurance Claims 

## Overview

This SQL project analyzes insurance customer data to uncover claim patterns, customer risk factors, and regional performance. The project includes data cleaning, customer segmentation, KPI analysis, and risk assessment.

## Skills Demonstrated

- Data Cleaning
- CTEs
- Window Functions
- Aggregate Functions
- CASE Statements
- Customer Segmentation
- Ranking & Contribution Analysis

## Analysis Performed

- Removed duplicate and incomplete records
- Calculated total customers, total claims, and average claims
- Analyzed claims by region, gender, BMI category, and age group
- Segmented customers into risk categories
- Identified top insurance claims using `DENSE_RANK()`
- Calculated regional contribution to total claims

## Key Insights

- Higher BMI levels were associated with larger claim amounts.
- High-risk customers generated the highest average claims.
- Claim amounts varied across regions and age groups.
- A small number of customers accounted for the highest claim values.
